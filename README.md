# Notes App

Android-приложение для создания, редактирования и организации заметок с поддержкой поиска, тегов, изображений, фильтрации, сортировки и напоминаний.

## Особенности и технические решения

### Архитектура (Clean Architecture)
Проект структурирован по принципам Clean Architecture с чётким разделением ответственности по слоям:
* **Domain**: содержит бизнес-логику, доменные модели (`Note`, `Tag`), интерфейсы репозиториев и Use Cases (`GetNotesUseCase`, `SaveNoteUseCase`, `DeleteNoteUseCase`).
* **Data**: содержит реализацию репозитория (`NoteRepositoryImpl`), работу с Room Database (`NoteDao`, `NoteEntity`), конвертеры данных, а также механизмы системных уведомлений.
* **Presentation**: построен на Jetpack Compose с использованием шаблона MVVM / UDF (Unidirectional Data Flow). Состояние экрана инкапсулировано в `UiState`, а действия пользователя передаются через `UiEvent`.

### Фильтрация и поиск
В `GetNotesUseCase` и `NotesListViewModel` реализована фильтрация данных на основе реактивных потоков (Kotlin Flow). 
* Поиск по заголовку и содержимому, фильтры по тегам, наличию изображений, а также статусу черновика объединяются через оператор `combine`.
* Оператор `flatMapLatest` перезапускает подписку на источник данных при изменении любых параметров фильтрации или поиска.
* Поддерживается сортировка по дате обновления, дате создания, длине текста и алфавиту.

### Система напоминаний и Deep Linking
* **Планировщик задач**: класс `ReminderScheduler` использует системный `AlarmManager` для установки будильника (`setExactAndAllowWhileIdle`).
* **Приёмник уведомлений**: `NoteReminderReceiver` отлавливает срабатывание будильника, формирует канал уведомлений (Notification Channel) и отправляет push-уведомление.
* **Навигация по клику**: при нажатии на уведомление приложение открывает соответствующий экран редактирования заметки благодаря настраиваемому Deep Link (`app://notes/edit/{noteId}`) внутри Navigation Compose.

### Управление черновиками и изменениями
* При редактировании заметки приложение автоматически отслеживает состояние полей и сравнивает их с исходными данными (`hasChanges`).
* При нажатии кнопки «Назад» неотправленные изменения автоматически сохраняются в статусе черновика (`isDraft = true`).

## Стек технологий и библиотеки

### Основные компоненты
* **Kotlin**: основной язык разработки, используются Coroutines и Flow.
* **Jetpack Compose**: фреймворк для построения пользовательского интерфейса.
* **Material 3**: система дизайна компонентов, включая кастомную цветовую палитру (`ColorScheme`).

### Используемые библиотеки
* **Room Database**: локальная база данных SQLite для надежного хранения заметок и тегов.
* **Koin (`koin-android`, `koin-androidx-compose`)**: легкий фреймворк внедрения зависимостей (Dependency Injection).
* **Navigation Compose**: навигация между экранами в приложении с поддержкой аргументов и Deep Links.
* **Coil (`coil-compose`)**: асинхронная загрузка и кэширование изображений для отображения в списке.

## Инструкция по сборке

1. **Клонирование репозитория:**
   ```bash
   git clone [https://github.com/stepchik003/Notes.git](https://github.com/stepchik003/Notes.git)
   ```
2. Запустите Android Studio, выберите **File -> Open** и укажите корневую папку проекта.
3. Дождитесь завершения процесса Gradle Sync.
4. Выберите конфигурацию `app` на верхней панели и нажмите **Run** (`Shift + F10`) для запуска на эмуляторе или физическом устройстве.

## Или скачать готовый релиз (APK)
1. Перейдите в раздел [Releases](https://github.com/stepchik003/Notes/releases).
2. Скачайте файл `notes.apk` из последнего опубликованного релиза.
3. Откройте файл на Android-устройстве и подтвердите установку (при необходимости разрешите установку из неизвестных источников в настройках системы).
